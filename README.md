# Python LLM API Learning Project

A beginner-friendly project created to explore Python programming, Large Language Model (LLM) API integration, and FastAPI fundamentals.

## Features
- Basic Python programming exercises and loops
- LLM API integration
- Introduction to building APIs with FastAPI
- Basic chat history handling

## Technologies Used
- Python
- FastAPI
- LLM API
- Git and GitHub

## Purpose
This project is part of my learning journey in Python and Generative AI. It helps me understand how to connect Python applications to an LLM API and explore the fundamentals of API development.
